# ADR 0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-19

## Context

Eureka SysML is a long project with one maintainer, AI-assisted development and, we hope, future contributors. Decisions and spec interpretations have to survive beyond any single conversation.

## Decision

Record significant decisions in `docs/adr/NNNN-title.md`, using this format: Status, Date, Context, Decision, Consequences. **Every interpretation of an ambiguous spec clause also gets an ADR.**

## Consequences

Reviewers and tools (including Claude Code through `CLAUDE.md`) can find out why something is the way it is. Superseded ADRs stay in place and are marked as superseded.
