# Step 1a.0 evidence: dependency spike

- Date: 2026-11-20
- Step: 1a.0 of the Phase 1 execution plan
- Purpose: evidence for decisions D1 (parser architecture, evaluated in 1a.2) and D2 (`salsa`, evaluated in 1a.7). This record does not decide them (execution plan §2.5).

## Question

Do the candidate dependencies meet the constraints every crate in this workspace must meet: they build for `wasm32-unknown-unknown`, work on the declared minimum Rust version (1.89), and pass `cargo deny` with our `deny.toml`? And do they *work* on wasm32, not just compile?

## Method

A throwaway crate, outside the workspace, makes each dependency do one real thing:
- **`rowan`:** build a lossless tree and get the original text back.
- **`salsa`:** change an input and check that a derived query recomputes.
- **`uuid`** with the `v5` feature: compute the KerML 9.1 UUID of the `ScalarValues` package, and compare it with the D7 oracle (ADR 0009).
- **`wasm-bindgen`:** export a function.

The three tests ran natively and as WebAssembly under Node (`wasm-bindgen-test`), each with the stable toolchain and with Rust 1.89. `cargo deny check` ran with a copy of the repository's `deny.toml`.

To repeat: create the two files below in an empty folder, install `wasm-bindgen-cli` at the exact version of the `wasm-bindgen` crate (here 0.2.130), and run:

```sh
cargo test                                                # native, stable
RUSTUP_TOOLCHAIN=1.89 cargo test                          # native, minimum Rust version
CARGO_TARGET_WASM32_UNKNOWN_UNKNOWN_RUNNER=wasm-bindgen-test-runner \
  cargo test --target wasm32-unknown-unknown              # WebAssembly under Node (add RUSTUP_TOOLCHAIN=1.89 too)
cargo deny check --config <repository>/deny.toml
```

```rust
// SPDX-License-Identifier: Apache-2.0
//! Step 1a.0 spike: each candidate dependency does one real thing, natively and on wasm32.
use wasm_bindgen::prelude::*;

// ---- rowan: a lossless tree that reproduces its text ----
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
#[repr(u16)]
enum Kind { Word = 0, Space, Root }
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
enum Lang {}
impl rowan::Language for Lang {
    type Kind = Kind;
    fn kind_from_raw(raw: rowan::SyntaxKind) -> Kind { match raw.0 { 0 => Kind::Word, 1 => Kind::Space, _ => Kind::Root } }
    fn kind_to_raw(kind: Kind) -> rowan::SyntaxKind { rowan::SyntaxKind(kind as u16) }
}
pub fn rowan_round_trip(text: &str) -> String {
    let mut b = rowan::GreenNodeBuilder::new();
    b.start_node(rowan::SyntaxKind(Kind::Root as u16));
    for part in text.split_inclusive(' ') {
        let (word, space) = part.split_at(part.trim_end_matches(' ').len());
        if !word.is_empty() { b.token(rowan::SyntaxKind(Kind::Word as u16), word); }
        if !space.is_empty() { b.token(rowan::SyntaxKind(Kind::Space as u16), space); }
    }
    b.finish_node();
    rowan::SyntaxNode::<Lang>::new_root(b.finish()).text().to_string()
}

// ---- salsa: an input and a derived query that updates on change ----
#[salsa::input]
pub struct File { #[returns(ref)] pub text: String }

#[salsa::tracked]
pub fn word_count(db: &dyn salsa::Database, file: File) -> usize { file.text(db).split_whitespace().count() }

#[salsa::db]
#[derive(Default, Clone)]
pub struct Db { storage: salsa::Storage<Self> }
#[salsa::db]
impl salsa::Database for Db {}

pub fn salsa_incremental() -> (usize, usize) {
    use salsa::Setter;
    let mut db = Db::default();
    let f = File::new(&db, "package A;".to_owned());
    let before = *word_count(&db, f); // salsa 0.28 returns a reference to the memoized value
    f.set_text(&mut db).to("package A { part def B; }".to_owned());
    (before, *word_count(&db, f))
}

// ---- uuid: KerML 9.1 top-level package UUID ----
pub fn library_package_uuid(prefix: &str, package: &str) -> String {
    uuid::Uuid::new_v5(&uuid::Uuid::NAMESPACE_URL, format!("{prefix}{package}").as_bytes()).to_string()
}

// ---- wasm-bindgen: an exported function ----
#[wasm_bindgen]
pub fn kerml_package_uuid(package: &str) -> String { library_package_uuid("https://www.omg.org/spec/KerML/", package) }

#[cfg(test)]
mod tests {
    use super::*;
    #[cfg(target_arch = "wasm32")]
    use wasm_bindgen_test::wasm_bindgen_test as test;

    #[test]
    fn rowan_is_lossless() { let t = "standard  library package ScalarValues "; assert_eq!(rowan_round_trip(t), t); }
    #[test]
    fn salsa_recomputes() {
        // "package A;" is 2 words and "package A { part def B; }" is 7.
        assert_eq!(salsa_incremental(), (2, 7));
    }
    #[test]
    fn uuid_matches_the_d7_oracle() {
        // KerML 9.1; the value is the elementId of ScalarValues in SysML-v2-Release 2025-02.
        assert_eq!(kerml_package_uuid("ScalarValues"), "40bb440c-5036-58e1-8675-5afccb8b8f1d");
    }
}
```

## Results

| Dependency | Version | License | Minimum Rust | wasm32 build | Works under Node | Notes |
|---|---|---|---|---|---|---|
| `rowan` | 0.17.0 | MIT OR Apache-2.0 | (not declared) | yes | yes | The newest release is `0.18.0-alpha.2`. 0.17.0 (2026-08) is the newest stable release. |
| `salsa` | 0.28.5 | Apache-2.0 OR MIT | 1.88 | yes | yes | See below |
| `uuid` (`v5`) | 1.29.3 | Apache-2.0 OR MIT | 1.89 | yes | yes | `v5` adds `sha1_smol` (BSD-3-Clause, allowed). The computed `ScalarValues` UUID equals the D7 oracle's. |
| `wasm-bindgen` | 0.2.130 | MIT OR Apache-2.0 | — | yes | yes | The test runner (`wasm-bindgen-cli`) must be the same version, and does not accept `cargo test -q`. |
| `wasm-bindgen-test` | 0.3.80 | MIT OR Apache-2.0 | — | — | yes | Dev-dependency |

All three tests passed in all four combinations: native and WebAssembly, each on stable and on Rust 1.89. The highest minimum Rust version in the dependency tree is 1.89 (`uuid`), equal to the workspace's.

### `salsa`

- **Works on wasm32 at runtime.** The incremental recomputation test passes under Node, single-threaded.
- **Default features** (`salsa_unstable`, `rayon`, `macros`, `inventory`, `accumulator`) bring 57 runtime dependencies, including `rayon` and `tracing`.
- **Smallest working set: `default-features = false, features = ["macros", "inventory"]`**, with 52 dependencies. Without `inventory`, queries are not registered automatically, and the first query panics with "ingredient … was not registered".
- **API detail:** tracked queries return a reference to the memoized value (`&usize`), so a value is copied out before the database is mutated.
- **License: `cargo deny` fails on one crate.** `foldhash` 0.2.0 is Zlib-licensed and is not optional. It comes through `salsa` → `hashlink` → `hashbrown` 0.17, and no `salsa` feature removes it. With `Zlib` added to a scratch copy of `deny.toml`, every check passes (advisories, bans, licenses, sources). `Zlib` was removed from `deny.toml` in Phase 0 because no dependency used it. Re-allowing it is a license-policy change, so under the methodology (§2.5, point 6) it needs the owner's approval. **The owner approved it on 2026-11-20, and `Zlib` is allowed in `deny.toml` again.**
- `cargo deny` also warns about duplicate versions of `hashbrown` (0.14.5 and 0.17.1) and `rustc-hash` (1.1.0 and 2.1.3). The policy allows this (`multiple-versions = "warn"`).

## What this means for the decisions

- **D1 (1a.2):** `rowan` 0.17 meets the constraints. The evaluation should use the stable 0.17, not the 0.18 alpha.
- **D2 (1a.7):** `salsa` 0.28 meets every constraint, now that `Zlib` is allowed. The evaluation should start from the minimal feature set (`macros`, `inventory`).
- **1a.1 (WASM test harness):** the `wasm-bindgen-test-runner` approach works for the workspace, and CI needs `wasm-bindgen-cli` pinned to the `wasm-bindgen` version.
