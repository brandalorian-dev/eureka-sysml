# Step 1a.11 evidence: the library snapshot (D5) and CI timing gates (D6)

- Date: 2026-11-24
- Step: 1a.11 of the Phase 1 execution plan
- Purpose: the evidence for decisions D5 (snapshot format for the pre-resolved libraries, ADR 0024) and D6 (how CI gates timings, ADR 0025), under the decision methodology (execution plan §2.5)

## Questions

1. **Is a snapshot needed?** The `library-load` budget (PROJECT_PLAN §7) is < 300 ms on the server and < 1 s in the browser, for all 10 standard libraries, "from the pre-resolved snapshot". How long do they take from text?
2. **What must a snapshot hold, and how does the engine use it?** The engine's results are `salsa` queries (ADR 0019). salsa 0.28 can persist its memo tables; the alternative is an image built by hand.
3. **Which format?** The recommended default is a versioned binary format through a serde-compatible crate such as `postcard`.
4. **How can CI gate a timing?** The recommended default is instruction counts on GitHub-hosted runners, with wall-clock budgets measured but not gated (ADR 0007).

## Options

- **D5, mechanism.**
  - (a) salsa's own persistence: serialize the database, inputs and memos, and load it into a new one.
  - (b) a hand-built library image: per file, the lowered graph, every name end resolved, and the overlay (ADR 0022). Three queries, `lowered`, `resolve_end` and `overlay`, answer from it when a file has one; every other query is computed on demand, as from text.
  - The baseline: no snapshot, loading from text.
- **D5, format.** postcard (the default) and bincode 1, both serde; CBOR (`ciborium`) and JSON where postcard and bincode cannot be used.
- **D6.** Instruction counts with Cachegrind (the default); wall-clock timings with a threshold, on the shared runners; a dedicated runner.

## Method

- **Code.** A copy of the workspace, outside the repository, with serde on the model's and the semantics' types. For (a), `persist` on the two inputs and on every tracked function except parsing, lowering, the violations and `library`. For (b), an optional image on `SourceFile` and the three short-circuits. Throwaway crates drive it: `spikea`, `spikeb`, and `spikebw` for WASM. The sources are in the appendix.
- **Workload.** The 36 KerML library files: their 4,003 names resolved (`resolved_names`) and their overlays built (52,327 implied elements). That is "ready": what loading must deliver.
- **Machines.**
  - The development machine: WSL2, AMD Ryzen AI 9 HX 370, 24 threads, release builds. WASM under Node through `wasm-bindgen-test-runner`, timed with `Date.now()`.
  - For D6, also three GitHub `ubuntu-24.04` runners, through a temporary workflow on a branch that was deleted afterwards.

## Results

### Loading from text (D5 baseline)

| KerML libraries, release | Parse | Lower | Resolve | Overlays | Total |
|---|---|---|---|---|---|
| Native | 3–4 ms | 4–7 ms | 55–62 ms | 162–174 ms | 224–248 ms |
| WASM (Node) | 3–10 ms | 5–14 ms | 58–101 ms | 163–204 ms | 229–329 ms |

The first WASM run includes the JIT's warm-up; the next two equal native. The SysML libraries are 1,224,817 bytes of text against the KerML libraries' 185,948, 6.6 times as much. Scaled by text, the 10 libraries take about 1.8 s native and 2.5 s in the browser: six and two and a half times the budgets. Parsing and lowering are 4% of it, so a snapshot that skipped only them would not help; it has to carry resolution and the overlays.

### (a) salsa persistence

| | Size | Serialize | Deserialize | Then ready |
|---|---|---|---|---|
| postcard | fails: "the length of a sequence must be known" | | | |
| bincode 1 | fails: "sequences and maps that have a knowable size" | | | |
| CBOR (ciborium) | 90,567,814 bytes | 975 ms | not possible: its `Deserializer` is private | |
| JSON | 135,330,830 bytes | 992 ms | 1,177–1,217 ms | 71–92 µs |

salsa writes sequences without a length, so neither postcard nor bincode can carry it. With JSON, a loaded database is ready at once: the memos come back valid. But it persists every memo and its dependencies: 135 MB for 186 KB of text. Loading it takes five times as long as loading from text. The 10 libraries would be about 0.7 GB.

### (b) A hand-built image

| KerML libraries | Size | Encode | Decode | Into the database | Then ready | Total |
|---|---|---|---|---|---|---|
| postcard, native | 4,822,843 bytes | 6.7 ms | 12–18 ms | 4–6 ms | 7–14 ms | 25–36 ms |
| bincode 1, native | 11,749,673 bytes | 6.9 ms | 11 ms | 6 ms | 7 ms | 23–24 ms |
| postcard, WASM (Node) | 4,822,843 bytes | | 19–23 ms (decode and load) | | 5–9 ms | 24–32 ms |

Building the images from a resolved database takes 24 ms. The image is about ten times faster than text, natively and as WASM. postcard and bincode load in the same time, and postcard's image is less than half the size. Scaled to the 10 libraries: about 190 ms native and 250 ms in the browser, and about 37 MB. The budgets are 300 ms and 1 s.

**What the image leaves to compute.** As a workload that only a user model would bring, the spike also took every library type's inherited memberships, 598,080 in all. After the image that took 721–754 ms; after loading from text, 818 ms. The image carries what loading needs, not every query a user model may ask about library elements. Those are computed when asked, once per project, as now.

**Isolation.** The image answers the name ends and overlays of its files whatever project asks. So a user project's own packages cannot change how library names resolve, which is what KerML 10.3's project usages mean for a library. The spike needed no change to how queries are keyed by project.

### D6: timings on the CI runners

The workload: the KerML libraries loaded from text, as above, by `d6_probe`, built in release.

| Runner | CPU | Wall clock, 3 × 20 runs | Spread in a run | Cachegrind `I refs`, 3 runs |
|---|---|---|---|---|
| GitHub 1 | AMD EPYC 9V74 | means 381.5, 381.9, 385.5 ms | 2.5–2.6% | 3,373,902,690 – 3,374,055,665 |
| GitHub 2 | Intel Xeon 6975P-C | means 260.5, 265.0, 265.7 ms | 1.9–2.7% | 3,373,952,147 – 3,374,067,966 |
| GitHub 3 | AMD EPYC 9V74 | means 332.6, 333.6, 335.4 ms | 2.2–2.6% | 3,373,904,985 – 3,374,047,414 |
| Development machine | Ryzen AI 9 HX 370 | means 256.3, 259.9, 262.1 ms | 2.7–3.2% | 3,378,446,862 – 3,378,658,456 |

- **Wall clock.** It is steady within a runner, but the means differ by 46% between runners, by 15% even between two of the same CPU model. A threshold that never fails falsely would miss any regression smaller than about half.
- **Instruction counts.** The nine runs on GitHub, on two CPU models, lie within 165,276 of 3.37 billion: 0.005%. The development machine counts 0.13% more, from its own toolchain and system libraries. So a baseline is taken on CI and compared on CI.

## Conclusions

- **D5.** A snapshot is needed: from text, the 10 libraries would be about six times over the server budget. salsa's persistence fails on size, at 135 MB for the KerML libraries alone; on load time, slower than text; and on format, since postcard and bincode cannot carry it. A hand-built image loads ten times faster than text, and is within both budgets at the scale of the 10 libraries. postcard is as fast as bincode at half the size. Adopted: the image, in postcard (ADR 0024).
- **D6.** Wall-clock timings cannot gate on shared runners: they differ by 46% from runner to runner. Instruction counts are reproducible to 0.005% across GitHub's runners. Adopted: a gate on Cachegrind's counts, against a baseline taken on CI; the wall-clock time is measured and reported against the budget, not gated (ADR 0025).
- **Limits.**
  - The scaling to 10 libraries is by text size, since the SysML libraries cannot be loaded before Phase 1b. Phase 1b measures it.
  - The browser was measured with Node's V8, not in a browser.

## Appendix: the spike sources

### The image (`sysml-semantics/src/image.rs` in the spike copy)

The short-circuits: `lowered` returns the image's lowered fragment, `resolve_end` looks up `(index, source?, position)` in its ends, and `overlay` returns its overlay. `Overlay::to_image` and `from_image` map each `Global` to and from a `(file position, index)` pair.

```rust
// SPDX-License-Identifier: Apache-2.0
//! Spike 1a.11 (b): a hand-built library image.
use std::collections::HashMap;
use std::sync::Arc;
use crate::lower::Lowered;
use crate::materialize::{Overlay, OverlayImage};
use crate::resolve::{Entry, Global, Project, SourceFile, Visibility};

/// The image of one file, with each Global as (file position, index).
#[derive(serde::Serialize, serde::Deserialize)]
pub struct FileImage {
    pub lowered: Lowered,
    pub ends: Vec<(u32, bool, u32, Option<EntryImage>)>,
    pub overlay: OverlayImage,
}

#[derive(serde::Serialize, serde::Deserialize)]
pub struct EntryImage {
    pub name: Option<Arc<str>>,
    pub short_name: Option<Arc<str>>,
    pub membership: (u32, u32),
    pub owned_element: Option<(u32, u32)>,
    pub visibility: Visibility,
    pub hidden: bool,
}

/// An image loaded into a database.
pub struct Resolved {
    pub lowered: Arc<Lowered>,
    pub ends: HashMap<(u32, bool, u32), Option<Entry>>,
    pub overlay: Overlay,
}

impl std::fmt::Debug for Resolved {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result { f.write_str("Resolved") }
}

/// The image of every file of a project, after computing it.
pub fn build(db: &dyn salsa::Database, project: Project) -> Vec<FileImage> {
    let files = project.files(db).clone();
    let index: HashMap<SourceFile, u32> = files.iter().enumerate().map(|(i, f)| (*f, i as u32)).collect();
    let pos = |g: Global| (index[&g.file], g.index);
    files.iter().map(|f| {
        let l = crate::resolve::structure(db, *f);
        let g = l.graph();
        let mut ends = Vec::new();
        for e in g.elements() {
            for (slot, list) in [(true, g.source(e)), (false, g.target(e))] {
                for (i, end) in list.iter().enumerate() {
                    if matches!(end, sysml_model::Endpoint::Name(_)) {
                        let s = if slot { sysml_model::Slot::Source } else { sysml_model::Slot::Target };
                        let r = crate::resolve::resolve_end(db, project, Global { file: *f, index: e.index() as u32 }, s, i as u32);
                        ends.push((e.index() as u32, slot, i as u32, r.as_ref().map(|r| EntryImage {
                            name: r.name.clone(), short_name: r.short_name.clone(), membership: pos(r.membership),
                            owned_element: r.owned_element.map(pos), visibility: r.visibility, hidden: r.hidden })));
                    }
                }
            }
        }
        let lw = crate::resolve::lowered(db, *f);
        FileImage {
            lowered: Lowered { graph: lw.graph.clone(), root: lw.root, diagnostics: Vec::new() },
            ends,
            overlay: crate::materialize::overlay(db, project, *f).to_image(&pos),
        }
    }).collect()
}

/// The resolved images, for the files of a new database, in order.
pub fn load(images: Vec<FileImage>, files: &[SourceFile]) -> Vec<Arc<Resolved>> {
    let global = |(f, i): (u32, u32)| Global { file: files[f as usize], index: i };
    images.into_iter().map(|i| Arc::new(Resolved {
        lowered: Arc::new(i.lowered),
        ends: i.ends.into_iter().map(|(r, s, p, e)| ((r, s, p), e.map(|e| Entry {
            name: e.name, short_name: e.short_name, membership: global(e.membership),
            owned_element: e.owned_element.map(global), visibility: e.visibility, hidden: e.hidden }))).collect(),
        overlay: Overlay::from_image(i.overlay, &global),
    })).collect()
}
```

### (a) salsa persistence (`spikea`)

```rust
use std::time::Instant;
use sysml_model::FileId;
use sysml_semantics::*;
fn ready(db: &Database, project: Project, files: &[SourceFile]) -> (usize, usize) {
    let mut n = 0; let mut i = 0;
    for f in files { n += resolved_names(db, project, *f).len(); }
    for f in files { i += overlay(db, project, *f).len(); }
    (n, i)
}
fn main() {
    let corpus = sysml_corpus::Corpus::load().unwrap();
    let kerml: Vec<_> = corpus.sources().filter(|s| s.language == sysml_corpus::Language::KerML).map(|s| (s.id.clone(), s.text.clone())).collect();
    let mut db = Database::default();
    let files: Vec<SourceFile> = kerml.iter().enumerate().map(|(i, (p, t))| SourceFile::new(&db, FileId(i as u32), p.clone(), sysml_syntax::Language::KerML, t.clone())).collect();
    let project = Project::new(&db, files.clone());
    let t = Instant::now();
    let r = ready(&db, project, &files);
    println!("from text: {:?} {:?}", t.elapsed(), r);
    let t = Instant::now();
    let pc = postcard::to_stdvec(&<dyn salsa::Database>::as_serialize(&mut db));
    println!("postcard serialize: {:?} {:?}", t.elapsed(), pc.as_ref().map(|v| v.len()).map_err(|e| e.to_string()));
    let t = Instant::now();
    let bc = bincode::serialize(&<dyn salsa::Database>::as_serialize(&mut db));
    println!("bincode serialize: {:?} {:?}", t.elapsed(), bc.as_ref().map(|v| v.len()).map_err(|e| e.to_string()));
    let t = Instant::now();
    let mut cb = Vec::new();
    let cbr = ciborium::into_writer(&<dyn salsa::Database>::as_serialize(&mut db), &mut cb);
    println!("cbor serialize: {:?} {} bytes {:?}", t.elapsed(), cb.len(), cbr.err().map(|e| e.to_string()));
    let t = Instant::now();
    let js = serde_json::to_vec(&<dyn salsa::Database>::as_serialize(&mut db));
    println!("json serialize: {:?} {:?}", t.elapsed(), js.as_ref().map(|v| v.len()).map_err(|e| e.to_string()));
    for (label, bytes) in [("postcard", pc.ok()), ("bincode", bc.ok()), ("cbor", Some(cb)), ("json", js.ok())] {
        let Some(bytes) = bytes else { continue };
        for run in 0..3 {
            let mut db2 = Database::default();
            let t = Instant::now();
            let res = if label == "cbor" {
                Err("ciborium's Deserializer is private".to_owned())
            } else if label == "json" {
                <dyn salsa::Database>::deserialize(&mut db2, &mut serde_json::Deserializer::from_slice(&bytes)).map_err(|e| e.to_string())
            } else if label == "postcard" {
                <dyn salsa::Database>::deserialize(&mut db2, &mut postcard::Deserializer::from_bytes(&bytes)).map_err(|e| e.to_string())
            } else {
                <dyn salsa::Database>::deserialize(&mut db2, &mut bincode::Deserializer::from_slice(&bytes, bincode::options())).map_err(|e| e.to_string())
            };
            let load = t.elapsed();
            let t = Instant::now();
            let r2 = res.as_ref().ok().map(|_| ready(&db2, project, &files));
            println!("{label} run {run}: deserialize {:?} {:?}; then ready {:?} {:?}", load, res.err(), t.elapsed(), r2);
        }
    }
}
```

### (b) the image (`spikeb`; `spikebw` runs the same as WASM)

```rust
use std::time::Instant;
use sysml_model::FileId;
use sysml_semantics::*;
fn ready(db: &Database, project: Project, files: &[SourceFile]) -> (usize, usize) {
    let mut n = 0; let mut i = 0;
    for f in files { n += resolved_names(db, project, *f).len(); }
    for f in files { i += overlay(db, project, *f).len(); }
    (n, i)
}
/// A lazy workload a user model triggers: the inherited memberships of every type.
fn warm(db: &Database, project: Project, files: &[SourceFile]) -> usize {
    let mut n = 0;
    for f in files {
        let g = structure(db, *f);
        for e in g.graph().elements() {
            if g.graph().metaclass(e).specializes(sysml_model::Metaclass::Type) {
                n += derived::inherited_membership(db, project, Global { file: *f, index: e.index() as u32 }).len();
            }
        }
    }
    n
}
fn main() {
    let corpus = sysml_corpus::Corpus::load().unwrap();
    let kerml: Vec<_> = corpus.sources().filter(|s| s.language == sysml_corpus::Language::KerML).map(|s| (s.id.clone(), s.text.clone())).collect();
    let db = Database::default();
    let files: Vec<SourceFile> = kerml.iter().enumerate().map(|(i, (p, t))| SourceFile::new(&db, FileId(i as u32), p.clone(), sysml_syntax::Language::KerML, t.clone(), None)).collect();
    let project = Project::new(&db, files.clone());
    let t = Instant::now(); let r = ready(&db, project, &files); let text_ready = t.elapsed();
    let t = Instant::now(); let w = warm(&db, project, &files); let text_warm = t.elapsed();
    println!("from text: ready {:?} {:?}; then warm {:?} ({w})", text_ready, r, text_warm);
    let t = Instant::now(); let images = image::build(&db, project); println!("build images {:?}", t.elapsed());
    let t = Instant::now(); let pc = postcard::to_stdvec(&images).unwrap(); println!("postcard: {} bytes, {:?}", pc.len(), t.elapsed());
    let t = Instant::now(); let bc = bincode::serialize(&images).unwrap(); println!("bincode: {} bytes, {:?}", bc.len(), t.elapsed());
    for (label, bytes) in [("postcard", &pc), ("bincode", &bc)] {
        for run in 0..3 {
            let t0 = Instant::now();
            let decoded: Vec<image::FileImage> = if label == "postcard" { postcard::from_bytes(bytes).unwrap() } else { bincode::deserialize(bytes).unwrap() };
            let t1 = Instant::now();
            let mut db2 = Database::default();
            let files2: Vec<SourceFile> = kerml.iter().enumerate().map(|(i, (p, _))| SourceFile::new(&db2, FileId(i as u32), p.clone(), sysml_syntax::Language::KerML, String::new(), None)).collect();
            let resolved = image::load(decoded, &files2);
            for (f, i) in files2.iter().zip(resolved) { use salsa::Setter; f.set_image(&mut db2).to(Some(i)); }
            let project2 = Project::new(&db2, files2.clone());
            let t2 = Instant::now();
            let r2 = ready(&db2, project2, &files2);
            let t3 = Instant::now();
            let w2 = warm(&db2, project2, &files2);
            let t4 = Instant::now();
            println!("{label} run {run}: decode {:?} load {:?} ready {:?} {:?}; total {:?}; then warm {:?} ({w2})", t1-t0, t2-t1, t3-t2, r2, t3-t0, t4-t3);
        }
    }
}
```

### D6: the probe and the temporary workflow

```rust
// SPDX-License-Identifier: Apache-2.0
//! Spike for decision D6 (step 1a.11), not merged: load the KerML libraries from text, either
//! `wall N` times with wall-clock timings, or `once` (for Cachegrind's instruction count).

use std::time::Instant;
use sysml_model::FileId;
use sysml_semantics::{overlay, resolved_names, Database, Project, SourceFile};
use sysml_syntax::Language;

fn load(sources: &[(String, String)]) -> usize {
    let db = Database::default();
    let files: Vec<SourceFile> = sources
        .iter()
        .enumerate()
        .map(|(i, (p, t))| SourceFile::new(&db, FileId(i as u32), p.clone(), Language::KerML, t.clone()))
        .collect();
    let project = Project::new(&db, files.clone());
    let mut n = 0;
    for f in &files {
        n += resolved_names(&db, project, *f).len();
    }
    for f in &files {
        n += overlay(&db, project, *f).len();
    }
    n
}

fn main() {
    let args: Vec<String> = std::env::args().collect();
    let sources: Vec<(String, String)> = sysml_corpus::Corpus::load()
        .unwrap()
        .sources()
        .filter(|s| s.language == sysml_corpus::Language::KerML)
        .map(|s| (s.id.clone(), s.text.clone()))
        .collect();
    match args.get(1).map(String::as_str) {
        Some("wall") => {
            let n: usize = args.get(2).and_then(|s| s.parse().ok()).unwrap_or(20);
            let mut ms: Vec<f64> = Vec::new();
            for _ in 0..n {
                let t = Instant::now();
                std::hint::black_box(load(&sources));
                ms.push(t.elapsed().as_secs_f64() * 1000.0);
            }
            let mean = ms.iter().sum::<f64>() / n as f64;
            let sd = (ms.iter().map(|x| (x - mean).powi(2)).sum::<f64>() / n as f64).sqrt();
            let min = ms.iter().cloned().fold(f64::MAX, f64::min);
            let max = ms.iter().cloned().fold(0.0, f64::max);
            println!("wall n={n} mean={mean:.1}ms sd={sd:.1}ms cv={:.1}% min={min:.1} max={max:.1}", 100.0 * sd / mean);
            println!("all: {}", ms.iter().map(|x| format!("{x:.1}")).collect::<Vec<_>>().join(" "));
        }
        _ => println!("{}", load(&sources)),
    }
}
```
