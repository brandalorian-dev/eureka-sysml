# Step 1a.7 evidence: incremental query spike (D2)

- Date: 2026-11-21
- Step: 1a.7 of the Phase 1 execution plan
- Purpose: the evidence for decision D2 (`salsa` and the boundaries of the incremental query graph, ADR 0019), under the decision methodology (execution plan §2.5)

## Questions

1. **Is incrementality needed?** Can recomputing everything after each edit, with no framework, meet the §7 budgets? Those are: re-resolve after a typical commit < 1 s on the server, and keystroke to diagnostics < 100 ms for a 50k-element working set.
2. **Does `salsa` recompute only what an edit affects?** Can a test observe that from its event log, as step 1a.7's tests require?
3. **Cycles.** KerML 8.2.3.5 lets imports and specializations form cycles, and the three KerML libraries are loaded as one circular unit. Can the queries resolve a cycle?
4. **What do the query boundaries cost?** That means where the queries should cut early, and the memory of memoizing.
5. **Constraints.** Does it build for wasm32, and on Rust 1.89?

## Method

A throwaway crate, `spike1a7`, outside the workspace, depends on `salsa` 0.28.5 (the features `macros` and `inventory`, as in the 1a.0 spike) and on the workspace's `sysml-syntax`, `sysml-semantics` (step 1a.6's lowering) and `sysml-model`.
- **The model.** `generate` writes one package per file. Each has 100 classifiers and 300 features, each feature typed by a classifier of its own package or of one of the two packages it imports. Both sizes are used: 50 files (55,250 elements) and 1,000 files (1,105,000 elements).
- **The resolver.** A minimal one, shared by both options, resolves every feature typing's name: in its own package, then in the packages it imports. That is a small part of KerML 8.2.3.5; the real resolution, implied relationships and validation will cost more.
- **Option B, no framework,** parses, lowers and resolves every file again.
- **Option A, `salsa`,** has these queries:
  - the inputs `File` (its text) and `Workspace` (the files);
  - `parsed` and `lowered` (no equality, so no backdating);
  - `file_package` and `file_exports` (a name-to-index map, which backdates);
  - `package_index` and `resolved` (per file).

  An event callback records each `WillExecute`.
- **The edits.** Each one changes one file, after which everything is resolved again:
  - E1 retypes a feature, without changing any name or index;
  - E2 adds white space only;
  - E3 adds a classifier, which changes the file's exports and the index of every later element.
- **The cycle.** A `visible` query (KerML 8.2.3.5.3) collects a package's own members and those its public imports make visible, using `salsa`'s fixpoint iteration (`cycle_initial` = the empty set). It runs on three packages that import each other in a circle, and then after an edit of one of them.
- **Measurement.** A release build on the development machine (WSL2), one run, with a counting allocator for the memory.

## Results

| | 50k elements | 1M elements |
|---|---|---|
| B: recompute everything | 36–45 ms | 663–1,029 ms |
| A: first run | 36 ms | 721 ms |
| A: E1, retype a feature | **0.97 ms** | **3.2 ms** |
| A: E2, white space | 0.84 ms | 3.0 ms |
| A: E3, add a classifier | 0.94 ms | 3.2 ms |
| A: memory, memoized | 36 MiB | 719 MiB |

- **Incrementality is needed.** At 1M elements, recomputing everything takes 0.66–1.03 s with the minimal resolver alone. That is already at or over the 1 s re-resolve budget, before the real resolution, the implied relationships and validation. With `salsa` an edit costs 3 ms. At 50k elements both options meet the 100 ms keystroke budget, but recomputing everything spends about 40 ms of it on parsing, lowering and the minimal resolution.
- **The event log shows exactly what reran.**
  - After E1 and E2: `parsed`, `lowered`, `file_package`, `file_exports` and `resolved` of the edited file, once each.
  - After E3: the same, plus `resolved` of the two files that import the edited one, 3 in all. This is the observation step 1a.7's incrementality test needs.
- **A boundary to refine.** After E2, a change of white space only, `resolved` still reran. `lowered` does not backdate, because a graph has no equality and its spans change. A span-free projection between lowering and resolution (the references to resolve) would stop such edits there.
- **Cycles converge.** With circular public imports (P0 → P1 → P2 → P0), each package's visible members are found by fixpoint iteration: all three of `A`, `B` and `C`. After `B2` is added to P1, P0's visible members include it, in 9 query executions.
- **Memory.** Memoizing the trees, fragments and intermediate results costs about 0.65 KB per element: 719 MiB at 1M elements on the server, and 36 MiB for a 50k working set in the browser (budget < 1 GB).
- **Constraints.** The spike builds for wasm32-unknown-unknown and on Rust 1.89. `salsa`'s only license outside the policy, `Zlib` (`foldhash`), was approved on 2026-11-20 (1a.0 spike).

```rust
//! The synthetic KerML model and the minimal resolver both options share.
use std::collections::{BTreeMap, HashMap};
use sysml_model::{Attr, Endpoint, FileId, Metaclass as M};
use sysml_semantics::{lower, Lowered};
use sysml_syntax::{parse, Language, Parse};
use uuid::Uuid;

/// `packages` files of one package each: `classifiers` classifiers and `features` features typed
/// by a classifier of the package itself or of one of the two packages it imports.
pub fn generate(packages: usize, classifiers: usize, features: usize) -> Vec<String> {
    (0..packages)
        .map(|i| {
            let (a, b) = ((i + 1) % packages, (i + 7) % packages);
            let mut t = format!("package P{i} {{\n    private import P{a}::*;\n    private import P{b}::*;\n");
            for k in 0..classifiers {
                t.push_str(&format!("    classifier C{i}_{k};\n"));
            }
            for k in 0..features {
                let j = [i, a, b][k % 3];
                t.push_str(&format!("    feature f{i}_{k} : C{j}_{};\n", k % classifiers));
            }
            t.push_str("}\n");
            t
        })
        .collect()
}

pub fn parse_file(text: &str) -> Parse {
    parse(Language::KerML, text)
}

pub fn lower_file(p: &Parse) -> Lowered {
    let mut n = 0u128;
    lower(FileId(0), &p.syntax(), &mut || {
        n += 1;
        Uuid::from_u128(n)
    })
}

/// The package of a file: its declared name and its member elements by name.
pub fn package_name(l: &Lowered) -> String {
    let g = &l.graph;
    g.owned_elements(l.root)
        .next()
        .and_then(|p| g.string(p, Attr::DeclaredName).map(str::to_owned))
        .unwrap_or_default()
}

pub fn exports(l: &Lowered) -> BTreeMap<String, u32> {
    let g = &l.graph;
    let Some(p) = g.owned_elements(l.root).next() else { return BTreeMap::new() };
    g.owned_elements(p)
        .filter_map(|e| g.string(e, Attr::DeclaredName).map(|n| (n.to_owned(), e.index() as u32)))
        .collect()
}

/// The imported package names of a file (`import X::*`).
pub fn imports(l: &Lowered) -> Vec<String> {
    let g = &l.graph;
    let Some(p) = g.owned_elements(l.root).next() else { return Vec::new() };
    g.owned_relationships(p)
        .iter()
        .filter(|r| g.metaclass(**r) == M::NamespaceImport)
        .filter_map(|r| match g.target(*r).first() {
            Some(Endpoint::Name(n)) => g.name(*n).segments.last().map(|s| s.to_string()),
            _ => None,
        })
        .collect()
}

/// Resolve every simple type name of a file: in its own package, then in the packages it imports.
/// `file_of` gives the file index of a package name, `exports_of` the exports of a file.
pub fn resolve<'a>(
    l: &Lowered,
    file_of: &HashMap<String, usize>,
    exports_of: impl Fn(usize) -> &'a BTreeMap<String, u32>,
    own: &BTreeMap<String, u32>,
) -> Vec<Option<(usize, u32)>> {
    let g = &l.graph;
    let imported: Vec<usize> = imports(l).iter().filter_map(|n| file_of.get(n).copied()).collect();
    let mut out = Vec::new();
    for x in g.elements() {
        if g.metaclass(x) != M::FeatureTyping {
            continue;
        }
        let Some(Endpoint::Name(n)) = g.target(x).first() else { continue };
        let name = &*g.name(*n).segments[0];
        let found = own.get(name).map(|ix| (usize::MAX, *ix)).or_else(|| {
            imported.iter().find_map(|f| exports_of(*f).get(name).map(|ix| (*f, *ix)))
        });
        out.push(found);
    }
    out
}
```

`src/main.rs`:

```rust
//! D2 spike (step 1a.7): salsa queries against recomputing everything, on a synthetic KerML model.
mod model;
use model::*;
use salsa::Setter;
use std::alloc::{GlobalAlloc, Layout, System};
use std::collections::{BTreeMap, HashMap};
use std::sync::atomic::{AtomicUsize, Ordering::Relaxed};
use std::sync::{Arc, Mutex};
use std::time::Instant;

struct Counting;
static LIVE: AtomicUsize = AtomicUsize::new(0);
unsafe impl GlobalAlloc for Counting {
    unsafe fn alloc(&self, l: Layout) -> *mut u8 { LIVE.fetch_add(l.size(), Relaxed); System.alloc(l) }
    unsafe fn dealloc(&self, p: *mut u8, l: Layout) { LIVE.fetch_sub(l.size(), Relaxed); System.dealloc(p, l) }
    unsafe fn realloc(&self, p: *mut u8, l: Layout, n: usize) -> *mut u8 {
        LIVE.fetch_add(n, Relaxed); LIVE.fetch_sub(l.size(), Relaxed); System.realloc(p, l, n)
    }
}
#[global_allocator]
static A: Counting = Counting;

// ---------- Option A: salsa ----------
#[salsa::input]
pub struct File {
    #[returns(ref)]
    pub text: String,
}

#[salsa::input]
pub struct Workspace {
    #[returns(ref)]
    pub files: Vec<File>,
}

#[salsa::tracked(returns(ref))]
fn parsed(db: &dyn salsa::Database, f: File) -> sysml_syntax::Parse {
    parse_file(f.text(db))
}

/// The lowered fragment. A Graph has no equality, so this query does not backdate.
#[salsa::tracked(returns(ref), no_eq)]
fn lowered(db: &dyn salsa::Database, f: File) -> Arc<sysml_semantics::Lowered> {
    Arc::new(lower_file(parsed(db, f)))
}

#[salsa::tracked(returns(ref))]
fn file_package(db: &dyn salsa::Database, f: File) -> String {
    package_name(lowered(db, f))
}

/// What a file exports by name: backdates when the names and indices are unchanged.
#[salsa::tracked(returns(ref))]
fn file_exports(db: &dyn salsa::Database, f: File) -> BTreeMap<String, u32> {
    exports(lowered(db, f))
}

#[salsa::tracked(returns(ref))]
fn package_index(db: &dyn salsa::Database, w: Workspace) -> HashMap<String, usize> {
    w.files(db).iter().enumerate().map(|(i, f)| (file_package(db, *f).clone(), i)).collect()
}

#[salsa::tracked(returns(ref))]
fn resolved(db: &dyn salsa::Database, w: Workspace, i: u32) -> Vec<Option<(usize, u32)>> {
    let files = w.files(db);
    let f = files[i as usize];
    let index = package_index(db, w);
    resolve(lowered(db, f), index, |j| file_exports(db, files[j]), file_exports(db, f))
}

#[salsa::db]
#[derive(Clone)]
struct Db {
    storage: salsa::Storage<Self>,
}
#[salsa::db]
impl salsa::Database for Db {}

fn salsa_db(log: Arc<Mutex<Vec<String>>>) -> Db {
    Db {
        storage: salsa::Storage::new(Some(Box::new(move |e: salsa::Event| {
            if let salsa::EventKind::WillExecute { database_key } = e.kind {
                log.lock().unwrap().push(format!("{database_key:?}"));
            }
        }))),
    }
}

fn resolve_all_a(db: &Db, w: Workspace) -> (usize, usize) {
    let n = w.files(db).len() as u32;
    let (mut ok, mut missing) = (0, 0);
    for i in 0..n {
        for r in resolved(db, w, i) {
            if r.is_some() { ok += 1 } else { missing += 1 }
        }
    }
    (ok, missing)
}

// ---------- Option B: recompute everything ----------
fn full(texts: &[String]) -> (usize, usize) {
    let lowered: Vec<_> = texts.iter().map(|t| lower_file(&parse_file(t))).collect();
    let index: HashMap<String, usize> = lowered.iter().enumerate().map(|(i, l)| (package_name(l), i)).collect();
    let exp: Vec<_> = lowered.iter().map(exports).collect();
    let (mut ok, mut missing) = (0, 0);
    for (i, l) in lowered.iter().enumerate() {
        for r in resolve(l, &index, |j| &exp[j], &exp[i]) {
            if r.is_some() { ok += 1 } else { missing += 1 }
        }
    }
    (ok, missing)
}

fn ms(t: Instant) -> f64 { t.elapsed().as_secs_f64() * 1e3 }

fn scenario(name: &str, packages: usize, classifiers: usize, features: usize) {
    let mut texts = generate(packages, classifiers, features);
    let elements: usize = texts.iter().map(|t| lower_file(&parse_file(t)).graph.len()).sum();
    println!("\n== {name}: {packages} files, {elements} elements");

    // B
    let t = Instant::now();
    let b = full(&texts);
    println!("B full recompute:          {:8.1} ms  resolved {} unresolved {}", ms(t), b.0, b.1);

    // A
    let log = Arc::new(Mutex::new(Vec::new()));
    let before = LIVE.load(Relaxed);
    let mut db = salsa_db(log.clone());
    let files: Vec<File> = texts.iter().map(|t| File::new(&db, t.clone())).collect();
    let w = Workspace::new(&db, files.clone());
    let t = Instant::now();
    let a = resolve_all_a(&db, w);
    println!("A first run:               {:8.1} ms  resolved {} unresolved {}  memory {:.0} MiB", ms(t), a.0, a.1, (LIVE.load(Relaxed) - before) as f64 / 1048576.0);
    assert_eq!(a, b);

    let mut edit = |db: &mut Db, label: &str, i: usize, new: String, texts: &mut Vec<String>| {
        texts[i] = new.clone();
        files[i].set_text(db).to(new);
        log.lock().unwrap().clear();
        let t = Instant::now();
        let a = resolve_all_a(db, w);
        let a_ms = ms(t);
        let executed = log.lock().unwrap().clone();
        let mut kinds: BTreeMap<String, usize> = BTreeMap::new();
        for e in &executed {
            *kinds.entry(e.split('(').next().unwrap_or("").to_owned()).or_default() += 1;
        }
        let t = Instant::now();
        let b = full(texts);
        let b_ms = ms(t);
        assert_eq!(a, b);
        println!("{label:26} A {a_ms:8.2} ms  B {b_ms:8.1} ms  re-executed: {kinds:?}");
    };
    // E1: retype one feature (a body edit: names and indices unchanged).
    let e1 = texts[3].replacen(&format!("feature f3_0 : C3_0;"), "feature f3_0 : C3_1;", 1);
    edit(&mut db, "E1 retype a feature", 3, e1, &mut texts);
    // E2: white space only.
    let e2 = texts[5].replacen("{\n", "{\n\n    ", 1);
    edit(&mut db, "E2 white space", 5, e2, &mut texts);
    // E3: add a classifier: the exports and every index after it change.
    let e3 = texts[7].replacen("classifier C7_0;", "classifier C7_0; classifier Extra;", 1);
    edit(&mut db, "E3 add a classifier", 7, e3, &mut texts);
}

// ---------- circular public imports (KerML 8.2.3.5: imports may be circular) ----------
/// The package names a file imports publicly (`public import X::*`).
fn public_imports(l: &sysml_semantics::Lowered) -> Vec<String> {
    use sysml_model::{Attr, Endpoint, Metaclass as M, Value};
    let g = &l.graph;
    let Some(p) = g.owned_elements(l.root).next() else { return Vec::new() };
    g.owned_relationships(p)
        .iter()
        .filter(|r| g.metaclass(**r) == M::NamespaceImport)
        .filter(|r| g.values(**r, Attr::Visibility).any(|v| *v == Value::Enumeration("public")))
        .filter_map(|r| match g.target(*r).first() {
            Some(Endpoint::Name(n)) => g.name(*n).segments.last().map(|s| s.to_string()),
            _ => None,
        })
        .collect()
}

/// The visible member names of a file's package (KerML 8.2.3.5.3): its own, and those its public
/// imports make visible, recursively. The imports may form a cycle: fixpoint iteration from the
/// empty set.
#[salsa::tracked(returns(ref), cycle_initial = visible_initial)]
fn visible(db: &dyn salsa::Database, w: Workspace, i: u32) -> std::collections::BTreeSet<String> {
    let files = w.files(db);
    let f = files[i as usize];
    let mut out: std::collections::BTreeSet<String> = file_exports(db, f).keys().cloned().collect();
    let index = package_index(db, w);
    for name in public_imports(lowered(db, f)) {
        if let Some(j) = index.get(&name) {
            out.extend(visible(db, w, *j as u32).iter().cloned());
        }
    }
    out
}

fn visible_initial(_db: &dyn salsa::Database, _id: salsa::Id, _w: Workspace, _i: u32) -> std::collections::BTreeSet<String> {
    std::collections::BTreeSet::new()
}

fn cycle() {
    let texts = [
        "package P0 { public import P1::*; classifier A; }",
        "package P1 { public import P2::*; classifier B; }",
        "package P2 { public import P0::*; classifier C; }",
    ];
    let log = Arc::new(Mutex::new(Vec::new()));
    let mut db = salsa_db(log.clone());
    let files: Vec<File> = texts.iter().map(|t| File::new(&db, (*t).to_owned())).collect();
    let w = Workspace::new(&db, files.clone());
    for i in 0..3 {
        println!("cycle: visible(P{i}) = {:?}", visible(&db, w, i));
    }
    files[1].set_text(&mut db).to("package P1 { public import P2::*; classifier B; classifier B2; }".to_owned());
    log.lock().unwrap().clear();
    println!("cycle after an edit of P1: visible(P0) = {:?}", visible(&db, w, 0));
    let n = log.lock().unwrap().len();
    println!("cycle: {n} query executions for the edit");
}

fn main() {
    cycle();
    // 50k elements: the browser working set of the keystroke budget (< 100 ms).
    scenario("50k", 50, 100, 300);
    // 1M elements: the re-resolve budget (< 1 s server).
    scenario("1M", 1000, 100, 300);
}
```
