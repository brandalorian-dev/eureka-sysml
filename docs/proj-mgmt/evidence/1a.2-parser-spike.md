# Step 1a.2 evidence: parser architecture and diagnostics spike

- Date: 2026-11-20
- Step: 1a.2 of the Phase 1 execution plan
- Purpose: the evidence for decisions D1 (parser architecture, ADR 0011) and D4 (diagnostics model, ADR 0012), under the decision methodology (execution plan §2.5)

## Questions

1. **D1, lexer.** Does a hand-written lexer, or one generated by `logos`, better implement KerML 8.2.2 and SysML 8.2.2.1.2? The criteria are correctness on the corpus, lossless output, error reporting, speed, and keyword tables per language.
2. **D1, parser.** How do hand-written recursive descent with a `rowan` tree (the default), tree-sitter and `pest` meet the constraints? Those are: the wasm32 build, the minimum Rust version (1.89), error recovery for an editor, a tree for invalid text, and losslessness.
3. **D4.** Can one diagnostic type serve every phase as a `salsa` query result? How must positions be stored for the Language Server Protocol?

## Method

Three throwaway crates, outside the workspace.

**`spike1a2`** holds two complete prototypes of the KerML 8.2.2 lexer, with the same token set and keyword tables chosen per language:
- `hand.rs`: a hand-written lexer.
- `generated.rs`: the same lexer with `logos` 0.16.

It also holds an option A prototype, `parse.rs`: the hand-written lexer, an event-based recursive-descent parser with error recovery for a small grammar fragment, a `rowan` 0.17 tree, and the D4 diagnostic type as a `salsa` 0.28 query.

`main.rs` runs both lexers over the 95 corpus sources (`sysml_corpus::Corpus::load`) and the 1M-element synthetic model (`sysml_synth`), in a release build, taking the best of 5 runs; ranges are across repeated invocations. It checks error tokens, losslessness and token-for-token agreement, and times them. It also lexes malformed inputs, and parses an input with two independent errors.

**`spikets`** builds the `tree-sitter` 0.27 crate natively and for wasm32-unknown-unknown.

**`spikepest`** parses the same two-error input with a small `pest` 2.9 grammar.

To repeat, put the files below in an empty folder next to a checkout of this repository, adjust the two `path` entries, and run `cargo run --release`.

### Lexer (D1)

|---|---|---|
| Corpus, 95 sources, 174,122 tokens: error tokens | 0 | 0 |
| Lossless on every source and on the 1M model | yes | yes |
| Agreement | identical tokens on all 95 sources and the 1M model | (same) |
| Corpus, 1.4 MB | 4.7–5.4 ms (264–302 MB/s) | 2.9–3.4 ms (418–479 MB/s) |
| 1M-element synthetic model, 7.4 MB, 1,891,154 tokens | 49.5–49.8 ms (148–149 MB/s) | 29.4–29.7 ms (249–251 MB/s) |
| `part def A { /* unterminated` | **1 error token** | **0 errors**: lexed silently as `/`, `*` and names |
| `x = "open string` + newline | 1 error token | 1 error token |
| `a é b ` + backquote + ` c` | 2 error tokens | 2 error tokens |
| `'it\'s' 1e 2E+5 a:::b` | no errors; `a`, `::`, `:`, `b` (KerML 8.2.2.7 longest match) | no errors |

`logos` also rejected the single-line note pattern `//[^\r\n]*` as an "unbounded greedy" repetition until `allow_greedy = true` was added. It cannot switch keyword tables per language, so both prototypes look keywords up after lexing a name. Its dependency tree adds `logos-codegen`, `logos-derive`, `regex-automata`, `regex-syntax`, `aho-corasick`, `memchr` and `fnv`.

### Parser (D1)

| | Hand-written + `rowan` (option A) | `pest` 2.9 | tree-sitter 0.27 |
|---|---|---|---|
| Builds natively | yes | yes | yes |
| Builds for wasm32-unknown-unknown | yes | yes | **no**: its C runtime needs `clang` for wasm32 ("failed to find tool clang") |
| Minimum Rust version | ≤ 1.89 | ≤ 1.89 | **1.90** (above the workspace's 1.89) |
| Input with two errors (`package A { feature x feature y; }` / `package B { feature ; }`) | **both reported**: `expected-semicolon` at 1:23, right after `x`; `expected-name` at 2:21 | **only the first**, as "expected feature" at 1:13, the start of `feature y`, not the missing `;` | not run (no wasm32 build) |
| Tree for invalid input | **yes, lossless**: 2 packages, 3 features recovered | **none** | — |
| Trivia (white space, notes) in the tree | yes | no: the implicit `WHITESPACE` rule is silent | — |
| Tree over all corpus tokens (174k) | 8.1 ms | — | — |
| Tree over the 1M-element model (1.9M tokens) | 141.6 ms | — | — |

tree-sitter grammars are written in JavaScript and compiled into a generated C parser, and its syntax tree is its own type, not `rowan`'s. `chumsky` advertises error recovery, but its 1.0 is still an alpha (`1.0.0-alpha.8`); it was not evaluated in depth.

### Diagnostics (D4)

- A `Vec<Diagnostic>` (derives `Clone, PartialEq, Eq, Hash, Debug`) works as a `salsa` tracked query result: 2 diagnostics for the two-error input, then 0 after the input is fixed.
- The diagnostic for `package 'Café' { feature ; }` is at byte offset 26, which is UTF-16 column 25 for the Language Server Protocol (its default position encoding): `é` is 2 bytes in UTF-8 but 1 UTF-16 unit. Positions must therefore be stored as byte ranges and converted at the protocol boundary.

```rust
//! Hand-written lexer: one pass over bytes, every byte in exactly one token.
use crate::{is_keyword, Kind, Lang, SYMBOLS};

pub fn lex(lang: Lang, text: &str) -> Vec<(Kind, u32)> {
    let b = text.as_bytes();
    let mut out = Vec::with_capacity(text.len() / 4);
    let mut i = 0;
    while i < b.len() {
        let start = i;
        let c = b[i];
        let kind = match c {
            b' ' | b'\t' | 0x0c | b'\n' | b'\r' => {
                while i < b.len() && matches!(b[i], b' ' | b'\t' | 0x0c | b'\n' | b'\r') { i += 1; }
                Kind::Whitespace
            }
            b'/' if b.get(i + 1) == Some(&b'/') && b.get(i + 2) == Some(&b'*') => block(b, &mut i, 3, Kind::BlockNote),
            b'/' if b.get(i + 1) == Some(&b'/') => {
                while i < b.len() && b[i] != b'\n' && b[i] != b'\r' { i += 1; }
                Kind::LineNote
            }
            b'/' if b.get(i + 1) == Some(&b'*') => block(b, &mut i, 2, Kind::RegularComment),
            b'a'..=b'z' | b'A'..=b'Z' | b'_' => {
                while i < b.len() && matches!(b[i], b'a'..=b'z' | b'A'..=b'Z' | b'_' | b'0'..=b'9') { i += 1; }
                if is_keyword(lang, &text[start..i]) { Kind::Keyword } else { Kind::Name }
            }
            b'0'..=b'9' => {
                while i < b.len() && b[i].is_ascii_digit() { i += 1; }
                // EXPONENTIAL_VALUE = DECIMAL_VALUE ('e'|'E') ('+'|'-')? DECIMAL_VALUE
                let mut j = i;
                if j < b.len() && (b[j] == b'e' || b[j] == b'E') {
                    j += 1;
                    if j < b.len() && (b[j] == b'+' || b[j] == b'-') { j += 1; }
                    if j < b.len() && b[j].is_ascii_digit() {
                        while j < b.len() && b[j].is_ascii_digit() { j += 1; }
                        i = j;
                        Kind::Exponential
                    } else { Kind::Decimal }
                } else { Kind::Decimal }
            }
            b'\'' => quoted(b, &mut i, b'\'', Kind::UnrestrictedName),
            b'"' => quoted(b, &mut i, b'"', Kind::String),
            _ => {
                if let Some(s) = SYMBOLS.iter().find(|s| b[i..].starts_with(s.as_bytes())) {
                    i += s.len();
                    Kind::Symbol
                } else {
                    // One character (UTF-8 aware) the lexical structure does not allow here.
                    i += text[i..].chars().next().map_or(1, char::len_utf8);
                    Kind::Error
                }
            }
        };
        out.push((kind, (i - start) as u32));
    }
    out
}

/// `/*` or `//*` … `*/`; unterminated runs to the end and is an error token.
fn block(b: &[u8], i: &mut usize, open: usize, kind: Kind) -> Kind {
    *i += open;
    while *i + 1 < b.len() {
        if b[*i] == b'*' && b[*i + 1] == b'/' { *i += 2; return kind; }
        *i += 1;
    }
    *i = b.len();
    Kind::Error
}

/// '…' or "…" with backslash escapes (KerML 8.2.2.3 Table 4); unterminated is an error token.
/// A line terminator ends it too, since NAME_CHARACTER and STRING_CHARACTER are printable characters.
fn quoted(b: &[u8], i: &mut usize, q: u8, kind: Kind) -> Kind {
    *i += 1;
    while *i < b.len() {
        match b[*i] {
            c if c == q => { *i += 1; return kind; }
            b'\\' if *i + 1 < b.len() => *i += 2,
            b'\n' | b'\r' => return Kind::Error,
            _ => *i += 1,
        }
    }
    Kind::Error
}
```

```rust
//! The same token set with the `logos` lexer generator. Keywords are looked up after lexing a name,
//! because logos cannot switch keyword tables per language.
use crate::{is_keyword, Kind, Lang};
use logos::Logos;

#[derive(Logos, Debug, PartialEq, Clone, Copy)]
enum Tok {
    #[regex(r"[ \t\x0C\r\n]+")] Ws,
    #[regex(r"//\*([^*]|\*+[^*/])*\*+/", priority = 4)] BlockNote,
    #[regex(r"//[^\r\n]*", priority = 3, allow_greedy = true)] LineNote,
    #[regex(r"/\*([^*]|\*+[^*/])*\*+/", priority = 4)] Comment,
    #[regex(r"[A-Za-z_][A-Za-z_0-9]*")] Name,
    #[regex(r"'([^'\\\r\n]|\\[^\r\n])*'")] Unrestricted,
    #[regex(r"[0-9]+")] Decimal,
    #[regex(r"[0-9]+[eE][+-]?[0-9]+")] Exponential,
    #[regex(r#""([^"\\\r\n]|\\[^\r\n])*""#)] Str,
    #[token("::>")] #[token(":>>")] #[token("===")] #[token("!==")] #[token("::")] #[token(":>")] #[token(":=")]
    #[token("**")] #[token("->")] #[token("..")] #[token("=>")] #[token("<=")] #[token("==")] #[token("!=")]
    #[token(">=")] #[token("??")] #[token(".?")] #[token("(")] #[token(")")] #[token("{")] #[token("}")]
    #[token("[")] #[token("]")] #[token(";")] #[token(",")] #[token("~")] #[token("@")] #[token("#")]
    #[token("%")] #[token("&")] #[token("^")] #[token("|")] #[token("*")] #[token("+")] #[token("-")]
    #[token("/")] #[token("$")] #[token(".")] #[token(":")] #[token("<")] #[token("=")] #[token(">")] #[token("?")]
    Symbol,
}

pub fn lex(lang: Lang, text: &str) -> Vec<(Kind, u32)> {
    let mut out = Vec::with_capacity(text.len() / 4);
    let mut lx = Tok::lexer(text);
    while let Some(t) = lx.next() {
        let len = lx.span().len() as u32;
        let kind = match t {
            Ok(Tok::Ws) => Kind::Whitespace,
            Ok(Tok::BlockNote) => Kind::BlockNote,
            Ok(Tok::LineNote) => Kind::LineNote,
            Ok(Tok::Comment) => Kind::RegularComment,
            Ok(Tok::Name) => if is_keyword(lang, lx.slice()) { Kind::Keyword } else { Kind::Name },
            Ok(Tok::Unrestricted) => Kind::UnrestrictedName,
            Ok(Tok::Decimal) => Kind::Decimal,
            Ok(Tok::Exponential) => Kind::Exponential,
            Ok(Tok::Str) => Kind::String,
            Ok(Tok::Symbol) => Kind::Symbol,
            Err(()) => Kind::Error,
        };
        out.push((kind, len));
    }
    out
}
```

```rust
//! Option A prototype: hand-written lexer -> event-based recursive descent with recovery -> rowan.
//! Grammar fragment: file = package* ; package = 'package' Name '{' feature* '}' ; feature = 'feature' Name ';'
use crate::{hand, Kind, Lang};

#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
#[repr(u16)]
pub enum SK { Ws, Note, Comment, Name, Keyword, Symbol, Other, ErrorTok, Error, Feature, Package, Root }
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub enum L {}
impl rowan::Language for L {
    type Kind = SK;
    fn kind_from_raw(r: rowan::SyntaxKind) -> SK { assert!(r.0 <= SK::Root as u16); unsafe_free(r.0) }
    fn kind_to_raw(k: SK) -> rowan::SyntaxKind { rowan::SyntaxKind(k as u16) }
}
fn unsafe_free(n: u16) -> SK { [SK::Ws, SK::Note, SK::Comment, SK::Name, SK::Keyword, SK::Symbol, SK::Other, SK::ErrorTok, SK::Error, SK::Feature, SK::Package, SK::Root][n as usize] }

/// D4 prototype: one diagnostic type for every phase.
#[derive(Clone, Debug, PartialEq, Eq, Hash)]
pub struct Diagnostic { pub code: &'static str, pub range: rowan::TextRange, pub message: String }

struct P<'a> { text: &'a str, toks: Vec<(SK, u32, u32)>, pos: usize, b: rowan::GreenNodeBuilder<'static>, diags: Vec<Diagnostic> }

fn sk(k: Kind) -> SK { match k {
    Kind::Whitespace => SK::Ws, Kind::LineNote | Kind::BlockNote => SK::Note, Kind::RegularComment => SK::Comment,
    Kind::Name | Kind::UnrestrictedName => SK::Name, Kind::Keyword => SK::Keyword, Kind::Symbol => SK::Symbol,
    Kind::Error => SK::ErrorTok, _ => SK::Other } }

impl<'a> P<'a> {
    fn trivia(&mut self) { while let Some(&(k, s, e)) = self.toks.get(self.pos) { if matches!(k, SK::Ws | SK::Note) { self.b.token(rowan::SyntaxKind(k as u16), &self.text[s as usize..e as usize]); self.pos += 1; } else { break } } }
    fn peek(&mut self) -> Option<(SK, &'a str)> { self.trivia(); self.toks.get(self.pos).map(|&(k, s, e)| (k, &self.text[s as usize..e as usize])) }
    fn at(&mut self, text: &str) -> bool { self.peek().is_some_and(|(_, t)| t == text) }
    fn bump(&mut self) { self.trivia(); let (k, s, e) = self.toks[self.pos]; self.b.token(rowan::SyntaxKind(k as u16), &self.text[s as usize..e as usize]); self.pos += 1; }
    fn here(&mut self) -> rowan::TextRange { self.trivia(); let o = self.toks.get(self.pos).map_or(self.text.len() as u32, |t| t.1); rowan::TextRange::empty(o.into()) }
    fn error(&mut self, code: &'static str, msg: &str) { let r = self.here(); self.diags.push(Diagnostic { code, range: r, message: msg.into() }); }
    fn expect(&mut self, text: &str, code: &'static str) -> bool {
        if self.at(text) { self.bump(); true } else { self.error(code, &format!("expected `{text}`")); false }
    }
    fn name(&mut self) { if self.peek().is_some_and(|(k, _)| k == SK::Name) { self.bump() } else { self.error("syntax::expected-name", "expected a name") } }
    /// Recovery: wrap tokens up to a synchronizing token in an Error node.
    fn recover(&mut self, until: &[&str]) {
        self.b.start_node(rowan::SyntaxKind(SK::Error as u16));
        while let Some((_, t)) = self.peek() { if until.contains(&t) { break } self.bump(); }
        self.b.finish_node();
    }
    fn feature(&mut self) {
        self.b.start_node(rowan::SyntaxKind(SK::Feature as u16));
        self.bump(); // 'feature'
        self.name();
        if !self.at(";") { self.error("syntax::expected-semicolon", "expected `;` after the feature declaration"); }
        else { self.bump(); }
        self.b.finish_node();
    }
    fn package(&mut self) {
        self.b.start_node(rowan::SyntaxKind(SK::Package as u16));
        self.bump(); self.name(); self.expect("{", "syntax::expected-brace");
        loop {
            match self.peek() {
                Some((_, "feature")) => self.feature(),
                Some((_, "}")) => { self.bump(); break }
                None => { self.error("syntax::expected-brace", "expected `}`"); break }
                Some(_) => { self.error("syntax::unexpected", "expected a feature or `}`"); self.recover(&["feature", "}", "package"]); if self.at("package") { break } }
            }
        }
        self.b.finish_node();
    }
}

pub fn parse(text: &str) -> (rowan::SyntaxNode<L>, Vec<Diagnostic>) {
    let mut off = 0u32;
    let toks = hand::lex(Lang::KerML, text).into_iter().map(|(k, l)| { let t = (sk(k), off, off + l); off += l; t }).collect();
    let mut p = P { text, toks, pos: 0, b: rowan::GreenNodeBuilder::new(), diags: Vec::new() };
    p.b.start_node(rowan::SyntaxKind(SK::Root as u16));
    while let Some((_, t)) = p.peek() { if t == "package" { p.package() } else { p.error("syntax::unexpected", "expected `package`"); p.recover(&["package"]) } }
    p.trivia();
    p.b.finish_node();
    (rowan::SyntaxNode::new_root(p.b.finish()), p.diags)
}

/// LSP positions are line and UTF-16 column (the protocol's default position encoding).
pub fn lsp_position(text: &str, offset: usize) -> (u32, u32) {
    let before = &text[..offset];
    let line = before.matches('\n').count() as u32;
    let col = before.rsplit('\n').next().unwrap_or("").encode_utf16().count() as u32;
    (line, col)
}

/// Build a flat rowan tree over every token, to measure tree-building cost.
pub fn flat_tree(lang: Lang, text: &str) -> rowan::GreenNode {
    let mut b = rowan::GreenNodeBuilder::new();
    b.start_node(rowan::SyntaxKind(SK::Root as u16));
    let mut off = 0usize;
    for (k, l) in hand::lex(lang, text) { b.token(rowan::SyntaxKind(sk(k) as u16), &text[off..off + l as usize]); off += l as usize; }
    b.finish_node();
    b.finish()
}

#[salsa::input] pub struct File { #[returns(ref)] pub text: String }
#[salsa::tracked(returns(ref))]
pub fn diagnostics(db: &dyn salsa::Database, f: File) -> Vec<Diagnostic> { parse(f.text(db)).1 }
#[salsa::db] #[derive(Default, Clone)] pub struct Db { storage: salsa::Storage<Self> }
#[salsa::db] impl salsa::Database for Db {}
```

```rust
use spike1a2::{generated, hand, Kind, Lang};
use std::time::Instant;

fn check(name: &str, lang: Lang, text: &str, totals: &mut [usize; 4]) {
    let h = hand::lex(lang, text);
    let g = generated::lex(lang, text);
    let lossless = |t: &[(Kind, u32)]| t.iter().map(|(_, l)| *l as usize).sum::<usize>() == text.len();
    let errs = |t: &[(Kind, u32)]| t.iter().filter(|(k, _)| *k == Kind::Error).count();
    if !lossless(&h) || !lossless(&g) || errs(&h) > 0 || errs(&g) > 0 || h != g {
        // First disagreement, for diagnosis.
        let mut off = 0usize; let mut first = None;
        for (a, b) in h.iter().zip(&g) { if a != b { first = Some((off, *a, *b)); break; } off += a.1 as usize; }
        println!("  {name}: lossless hand={} logos={}, errors hand={} logos={}, agree={} first diff {:?} near {:?}",
            lossless(&h), lossless(&g), errs(&h), errs(&g), h == g, first,
            first.map(|(o, _, _)| &text[o..(o + 40).min(text.len())]));
    }
    totals[0] += 1; totals[1] += h.len(); totals[2] += errs(&h); totals[3] += errs(&g);
}

fn time(f: impl Fn() -> usize) -> (f64, usize) {
    let mut best = f64::MAX; let mut n = 0;
    for _ in 0..5 { let t = Instant::now(); n = f(); best = best.min(t.elapsed().as_secs_f64()); }
    (best, n)
}

fn main() {

    let bad = "package A { feature x feature y; }\npackage B { feature ; }";
    let (tree, diags) = parse::parse(bad);
    println!("option A, two-error input: tree is lossless: {}", tree.text().to_string() == bad);
    for d in &diags {
        let (l, c) = parse::lsp_position(bad, usize::from(d.range.start()));
        println!("  {} at {}:{} ({})", d.code, l + 1, c + 1, d.message);
    }

    // D4: diagnostics as a salsa query, recomputed only when the text changes.
    { use salsa::Setter; let mut db = parse::Db::default(); let f = parse::File::new(&db, bad.to_owned());

      println!("D4 salsa: {} diagnostics, then {} after the fix", n1, parse::diagnostics(&db, f).len()); }
    // D4: LSP uses UTF-16 columns; offsets after a non-ASCII character differ.
    let t = "package 'Café' { feature ; }"; let (_, d) = parse::parse(t);
    println!("D4 position: byte offset {} -> LSP column {} (UTF-16)", usize::from(d[0].range.start()), parse::lsp_position(t, usize::from(d[0].range.start())).1);
    let corpus = sysml_corpus::Corpus::load().unwrap();

    for s in corpus.sources() {
        let lang = match s.language { sysml_corpus::Language::KerML => Lang::KerML, sysml_corpus::Language::SysML => Lang::SysML };
        check(&s.id, lang, &s.text, &mut totals);
    }

    let synth = sysml_synth::generate(&sysml_synth::Config::with_target_elements(sysml_synth::Config::LARGE));

    let all: String = corpus.sources().map(|s| s.text.as_str()).collect::<Vec<_>>().join("\n");
    for (label, text, lang) in [("corpus (all sources)", &all, Lang::SysML), ("synthetic 1M", &big, Lang::SysML)] {
        let mb = text.len() as f64 / 1e6;
        let (th, n) = time(|| hand::lex(lang, text).len());
        let (tg, _) = time(|| generated::lex(lang, text).len());
        println!("{label}: {mb:.1} MB, {n} tokens; hand {:.1} ms ({:.0} MB/s), logos {:.1} ms ({:.0} MB/s)",
            th * 1e3, mb / th, tg * 1e3, mb / tg);
        let (tt, _) = time(|| spike1a2::parse::flat_tree(lang, text).text_len().into());
        let g = spike1a2::parse::flat_tree(lang, text);
        println!("  rowan tree over all tokens: {:.1} ms, lossless: {}", tt * 1e3, rowan::SyntaxNode::<spike1a2::parse::L>::new_root(g).text() == text.as_str());
    }
    // Error handling: malformed input never fails and stays lossless.
    for bad in ["part def A { /* unterminated", "x = \"open string\n y;", "a \u{00e9} b ` c", "'it\\'s' 1e 2E+5 a:::b"] {
        let h = hand::lex(Lang::SysML, bad);
        let g = generated::lex(Lang::SysML, bad);
        let ok = |t: &[(Kind, u32)]| t.iter().map(|(_, l)| *l as usize).sum::<usize>() == bad.len();
        println!("malformed {bad:?}: hand lossless={} errors={} | logos lossless={} errors={}",
            ok(&h), h.iter().filter(|t| t.0 == Kind::Error).count(), ok(&g), g.iter().filter(|t| t.0 == Kind::Error).count());
    }
}
```

`spikepest/src/grammar.pest`:

```text
// A two-statement KerML-like fragment: `package N { (feature n;)* }`
WHITESPACE = _{ " " | "\t" | "\n" }
name       = @{ ASCII_ALPHA ~ (ASCII_ALPHANUMERIC | "_")* }
feature    = { "feature" ~ name ~ ";" }
package    = { "package" ~ name ~ "{" ~ feature* ~ "}" }
file       = { SOI ~ package* ~ EOI }
```

`spikepest/src/main.rs`:

```rust
use pest::Parser;
#[derive(pest_derive::Parser)]
#[grammar = "grammar.pest"]
struct P;
fn main() {
    let good = "package A { feature x; feature y; }";
    let r = P::parse(Rule::file, good).unwrap();
    let covered: usize = r.flatten().filter(|p| p.as_rule() == Rule::name).count();
    println!("valid input: parsed, {covered} names; whitespace kept in the tree: {}", good.contains(' ') && false);
    // Two independent errors: a missing ';' in A, and a missing name in B.
    let bad = "package A { feature x feature y; }\npackage B { feature ; }";
    match P::parse(Rule::file, bad) {
        Ok(_) => println!("two-error input: parsed (unexpected)"),
        Err(e) => println!("two-error input: one error, no tree:\n{e}"),
    }
}
```
